# Tianjic Controller 寄存器手册

| 项目 | 内容 |
|---|---|
| 映射版本 | v0.1.0 |
| 真源指纹 | md5=0c569873406e(gen_csr.py 自动生成,真源 `controller/csr/tj_ctrl_csr.yaml`,勿手改;同源再生成逐字节相同)|

## GLB(基址 0x0000)

控制器标识、控制与状态。

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | ID | [31:0] | — | RO | 0x544A4331(常量) | 控制器标识 TJC1（ASCII）。 |
| 0x04 | VERSION | [31:0] | — | RO | 0x100(常量) | 寄存器版本：[23:16]主版本，[15:8]次版本，[7:0]补丁版本。 |
| 0x08 | SCRATCH | [31:0] | — | RW | 0x0 | APB 读写自检，无控制副作用。 |
| 0x0C | CTRL | [0] | SRST | 脉冲 | — | 引擎软复位控制。<br>写1发起引擎软复位请求，读回0；不清除CSR配置。SEND停止新AXI请求和记录装填，等待在途AXI及已挂出的LVDS包收尾后归闲；中止本身不置DONE/ERR，已交付包仍计SENT并按记录IRQ标志通知；RECV清空尚未提交的通道缓冲，等待在途B响应后恢复，保留WPTR/RPTR；已使能通道在中止及排空期间按OVF_POLICY反压或丢弃并置OVF。BOOT接收事务边界中止请求，BOOT_PRIM中止时尝试写回CLK_SHIFT=0，处理中止不置DONE；SPI和配置链不接入此请求。 |
| 0x10 | STA | [7:0] | SPI_BUSY | RO | — | SPI/BOOT/SEND/CC 忙状态汇总。<br>各SPI引擎实际占用状态，含SPIWIN访问；门铃事务状态见各组SPI.STA.BUSY。 |
|  |  | [8] | BOOT_BUSY | RO | — | BOOT 引擎忙。 |
|  |  | [9] | SEND_BUSY | RO | — | SEND整体忙状态，包含取数、分发及事件送达等待。 |
|  |  | [10] | CC_BUSY | RO | — | FPGA 侧 LVDS 配置链忙。 |

## IRQ(基址 0x0100)

中断汇聚(事件位分配:详见手册附注;irq[3:0] 线映射在顶层)

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | RAW | [31:0] | — | W1C | 0x0 | 原始事件,硬件置位、写 1 清零。[7:0]=SPI 完成 [8]=BOOT 完成 [9]=SEND 完成/记录 irq 标志(同表多个 irq 标志合并为首次一报,进度以 SEND.SENT 追踪) [10]=CC 完成 [11]=TRACE 回绕 [23:12]=RECV 通道事件 [24]=SPI 超时 [25]=ECC 不可纠 [26]=链路停滞 [27]=RECV 溢出 [28]=AXI 响应错 [29]=BOOT 错 [31:30]=保留。位11、25、26未接硬件事件，可通过IRQ.TST置位。 |
| 0x04 | EN | [31:0] | — | RW | 0x0 | 事件使能掩码(1=参与 STA 与 irq 线) |
| 0x08 | STA | [31:0] | — | RO(派生) | — | 生效中断 = RAW & EN(只读派生) |
| 0x0C | TST | [31:0] | — | W1S | — | 测试注入:写 1 置位 RAW 对应位(探微集成联调中断链路用) |

## SYS(基址 0x0200)

芯片复位、时钟缓冲器使能与时间戳。

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | RST_LEVEL | [31:0] | — | RW | 0x0 | chip_rst_n[31:0]控制电平：0=保持复位，1=释放复位，复位值0。整字写入；读回设置值，不表示芯片就绪。错峰释放复位由Host更新位掩码并延时实现。 |
| 0x04 | CLK_CTL | [3:0] | — | RW | 0x0 | LMK1C1108时钟缓冲器使能输出clkctl[3:0]，复位值0；各位映射由板级连接定义。 |
| 0x08 | TS_CTRL | [0] | EN | RW | 0x0 | 48位时间戳控制，上行记录tag取低16位；写入同时更新EN/PRESC。<br>1=计数，0=暂停并保持计数值。 |
|  |  | [2:1] | PRESC | RW | 0x0 | maxi_clk预分频：0=/1，1=/16，2=/100，3=/1000；编码见tj_ts_div_e。 |
|  |  | [8] | CLR | 脉冲 | — | 写1发出清零请求，读回0；读回值不表示清零已完成。 |
| 0x0C | TS_LO | [31:0] | — | RO | — | 时间戳[31:0]。输入须为同步到pclk域的完整48位一致快照；连续计数时按TS_HI、TS_LO、TS_HI顺序读取，高位不同则重试。停计读取须等待停计生效及快照更新。 |
| 0x10 | TS_HI | [15:0] | — | RO | — | 时间戳[47:32]；本寄存器[31:16]读回0。完整读法见TS_LO。 |

## SPI(基址 0x0400)

实例 k 的寄存器地址 = 0x0400 + k×0x80 + 偏移;地址预留 8 实例,v1 例化 8(其余访问返回 pslverr)。

SPI组控制与状态；逻辑接口为组内4个die共用SCLK/MOSI、独立CS/MISO。CLKDIV/TMO与SPIWIN、BOOT共用。

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | CMD | [1:0] | KIND | RW | 0x0 | 门铃事务类型与目标die。<br>0=32位单写（0x00），1=32位单读（引擎完成0x06请求和0x04取数）；2/3保留，当前为空操作，置DONE且不发SPI事务。 |
|  |  | [5:4] | DIE | RW | 0x0 | 组内die编号0～3，对应逻辑片选cs_n[组号*4+DIE]。 |
| 0x04 | ADDR | [31:0] | — | RW | 0x0 | 芯片侧32位AHB字节地址，须4字节对齐。 |
| 0x08 | WDATA | [31:0] | — | RW | 0x0 | 32位单写数据（KIND=0）。 |
| 0x0C | RDATA | [31:0] | — | RO | — | 32位单读返回值，KIND=1且本次事务正常完成后有效。 |
| 0x10 | CLKDIV | [7:0] | — | RW | 0x4 | SCLK=pclk/[2*(DIV_eff+1)]，DIV_eff=max(CLKDIV,1)；写0回读0，实际按1处理。软件须保证SCLK≤芯片sys_clk/4且≤25MHz。 |
| 0x14 | TMO | [31:0] | — | RW | 0xF4240 | SPI引擎执行超时阈值，单位pclk周期，0=关闭。从引擎接受命令后计时，不含等待仲裁。超时中止传输并拉高CS，保持引擎忙且不接收新命令，等待普通帧间隔或块排空间隔后报告错误，不自动重试。写超时不保证撤销写入；单写和块写均可能改写目标地址或芯片此前锁存的地址，块写目标区须视为不可靠。 |
| 0x18 | DB | [0] | GO | 脉冲 | — | 事务启动请求。<br>空闲时写1请求执行CMD/ADDR/WDATA指定的事务；忙时忽略且不排队，读回0。 |
| 0x1C | STA | [0] | BUSY | RO | — | 门铃事务状态；DONE/ERR_TMO读不清、写1清、写0无影响，新GO不清除旧标志。<br>1=本门铃事务等待仲裁或执行中。 |
|  |  | [8] | DONE | W1C | 0x0 | 事务完成事件。 |
|  |  | [9] | ERR_TMO | W1C | 0x0 | 本门铃事务超时事件。 |
| 0x40~0x7C | BUF | — | — | 预留 | — | 预留16×32位数据缓冲，当前不生成RTL。 |

## BOOT(基址 0x0800)

引导引擎:DDR → SPI 事务层流式通路(固件装载/引导原语共用同一条数据路)

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | CMD | [1:0] | KIND | RW | 0x0 | 操作命令<br>0=FW_LOAD，1=BOOT_PRIM。2/3保留；写GO后以ERR_CODE=3错误完成，不发起DDR或SPI事务。 |
|  |  | [8:4] | DIE | RW | 0x0 | 目标 die 全局编号 0~31(多 die 由 host 循环敲门) |
| 0x04 | SRC_LO | [31:0] | — | RW | 0x0 | DDR 源地址低 32 位。源地址须按 64 字节对齐。BOOT_PRIM 模板由驱动预置于 DDR，长度由 BOOT.LEN 指定。 |
| 0x08 | SRC_HI | [15:0] | — | RW | 0x0 | DDR 源地址 [47:32] |
| 0x0C | LEN | [31:0] | — | RW | 0x0 | 装载长度，单位为字节，必须大于 0。FW_LOAD 长度须为 64 的倍数。BOOT_PRIM 长度可取 32、64、96 或 128 字节。非法长度返回 ERR_CODE=3。 |
| 0x10 | DST | [31:0] | — | RW | 0x0 | 芯片侧目标地址。FW_LOAD用于ILM/DLM，须64字节对齐，末字节不得超过0xFFFFFFFF。BOOT_PRIM须32字节对齐，整段须位于核内存0x02000000至0x0207FFFF。BOOT_PRIM启动前，软件须保证目标核SRAM可写并退出Light Sleep，通过SPIWIN在同一die写0x02FFF000=0x001使能配置且关闭广播，再向0x02FFF00C写入选核值（y左移2位，与x按位或）；SPIWIN.PAGE.DIE须与BOOT.CMD.DIE一致。任务结束前保持该die的配置使能、广播状态和选核不变，CLK_SHIFT由引擎控制。 |
| 0x14 | DB | [0] | GO | 脉冲 | — | 门铃<br>写1发起；BUSY=1时忽略。 |
| 0x18 | STA | [0] | BUSY | RO | — | 状态<br>进行中 |
|  |  | [8] | DONE | W1C | 0x0 | 完成 |
|  |  | [9] | ERR | W1C | 0x0 | 出错(见 ERR_CODE) |
|  |  | [15:12] | ERR_CODE | RO | — | 1=SPI超时，2=AXI读错，3=KIND、LEN或DST非法。其余编码保留。BOOT_PRIM因SPI超时结束后，CLK_SHIFT可能未恢复为0，软件应在重试或启动前恢复。 |

## SEND(基址 0x0C00)

下行 SEND 引擎:DDR 记录表 → 解析 → 按 ch 重映射分发 → LVDS 缝

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | SRC_LO | [31:0] | — | RW | 0x0 | 记录表 DDR 基址 [31:0],64B 对齐(低 6bit 硬件强制清零);门铃前程序、发送中勿改(跨域采样契约) |
| 0x04 | SRC_HI | [15:0] | — | RW | 0x0 | 记录表 DDR 基址 [47:32] |
| 0x08 | CNT | [31:0] | — | RW | 0x0 | 记录条数(16B/条;0=空表立即 DONE);门铃前程序、发送中勿改 |
| 0x0C | DB | [0] | GO | 脉冲 | — | 门铃<br>写 1 启动一次表发送(遇 flags.last 或计满 CNT 停);BUSY=1 时门铃被丢弃 |
| 0x10 | STA | [0] | BUSY | RO | — | 状态<br>启动准备、取数、分发或本表事件送达等待中。 |
|  |  | [8] | DONE | W1C | 0x0 | 本表处理完成（有错也置，错误详情看ERR）；在pclk侧观察到BUSY清零后置位。 |
|  |  | [9] | ERR | W1C | 0x0 | AXI读错（表中止）或记录非法/通道未使能（该记录丢弃、表继续）。同表错误合并上报，在本表DONE前置位；软件启动新任务前应清除旧状态。 |
| 0x14 | SENT | [31:0] | — | RO | — | 已被LVDS接口接受的记录数；源域在新任务启动时清零，丢弃记录不计。通过整字快照跨域，读值可能滞后；DONE不保证最终计数已刷新，连续读值相同也不证明已取得终值。 |

## RECV(基址 0x1000)

实例 k 的寄存器地址 = 0x1000 + k×0x40 + 偏移;地址预留 12 实例,v1 例化 3(其余访问返回 pslverr)。

上行 RECV 通道(每 LVDS 逻辑 ch 一套环形缓冲;v1 例化 3 通道,4~12 预留)

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | RING_LO | [31:0] | — | RW | 0x0 | DDR环形缓冲基址[31:0]，须64B对齐。用于软件双缓冲切换、容量调整或任务切换；先暂停该通道输入，写EN=0并等待STA.IDLE=1后修改。已收记录仍按锁存地址写入旧环。 |
| 0x04 | RING_HI | [15:0] | — | RW | 0x0 | 环形缓冲基址[47:32]；使用约定同RING_LO。 |
| 0x08 | SIZE | [31:0] | — | RW | 0x0 | 环容量，单位为记录条数，须为2的幂；仅EN=0且STA.IDLE=1时修改。 |
| 0x0C | WMARK | [31:0] | — | RW | 0x0 | 未消费记录数向上跨过该阈值时产生水线事件；仅EN=0且STA.IDLE=1时修改。 |
| 0x10 | CTRL | [0] | EN | RW | 0x0 | 通道控制<br>通道使能；0表示接收后丢弃新包，不取消已收记录。先写环参数，再写EN=1；同步到maxi_clk后再延迟2拍启用，此前到达的包按关闭处理。写0经同步后停收。 |
|  |  | [1] | OVF_POLICY | RW | 0x0 | 环满或软中止排空期间的处理策略：0=丢弃新包并置OVF，1=反压链路。 |
|  |  | [8] | IE_WMARK | RW | 0x0 | 水线事件参与 IRQ.RAW 通道位 |
|  |  | [9] | IE_END | RW | 0x0 | end 包事件参与 IRQ.RAW 通道位 |
| 0x14 | STA | [0] | WMARK_HIT | W1C | 0x0 | 接收通道状态。水线和END事件按写响应置位，进度快照可能稍后刷新；写入是否成功须结合AXI写错误状态判断。<br>水线越线沿(自下而上跨过 WMARK) |
|  |  | [1] | ENDPKT | W1C | 0x0 | END 记录的写响应完成；ptype[2]=1 且 ptype[0]=0，记录 flags[0]=1。 |
|  |  | [2] | OVF | W1C | 0x0 | 已使能通道在环满或软中止排空期间按策略0丢弃了新包；写1清除。 |
|  |  | [5] | IDLE | RO | — | 引擎已看到EN=0，且该通道没有缓冲或在途记录，与WPTR来自同一快照。EN=1时恒为0；EN从1清0后，等待3次快照刷新才允许置1。软件等本位为1后再读取最终WPTR或更换环参数；写入是否成功仍需检查AXI错误状态。 |
|  |  | [31:16] | LEVEL | RO | — | pclk域按WPTR快照减RPTR计算的未消费记录数，取低16位；容量达到65536条时应由软件使用完整指针计算。 |
| 0x18 | WPTR | [31:0] | — | RO | — | 已完成写响应的累计记录数，含错误响应。通过整字快照返回，更新可能滞后于接收引擎。 |
| 0x1C | RPTR | [31:0] | — | RW | 0x0 | Host 已消费记录的累计值，消费完成后单调回写。通过整字快照送往接收引擎；空间释放在快照到达后生效，APB写完成不表示接收侧已更新。 |

## CC(基址 0x3800)

| 偏移 | 寄存器 | 位 | 字段 | 类型 | 复位 | 说明 |
|---|---|---|---|---|---|---|
| 0x00 | CMD | [1:0] | KIND | RW | 0x0 | 选择链操作和本地LVDS实例。<br>0=写地址拍，1=写数据拍，2/3=读地址拍并等待返回；读操作无需先发KIND=0。 |
|  |  | [5:4] | INST | RW | 0x0 | 本地lvds_subsys实例ID，与目标CORE_ID匹配；v1仅用0，不是芯片die编号。 |
